# Learn C++ — От компилятора и памяти до прикладных проектов

Репозиторий прохождения углубленного практического курса по современному **C++ (C++17 / C++20 / C++23)**.

## Структура репозитория
- [`AGENTS.md`](./AGENTS.md) — правила менторства, стандарты код-ревью и трекер текущего прогресса.
- [`docs/SYLLABUS.md`](./docs/SYLLABUS.md) — полная программа курса (100 уроков в 12 модулях).
- [`docs/`](./docs/) — конспекты лекций (`lesson-X-N.md`), создаваемые по мере прохождения курса.
- [`tasks/`](./tasks/) — решения практических задач (`task-X-N/`), отчеты об экспериментах (`REPORT.md`) и код-ревью (`REVIEW.md`).
